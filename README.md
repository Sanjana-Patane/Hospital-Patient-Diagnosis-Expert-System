

# Hospital Patient Diagnosis Expert System

## Practical Assignment 1.2

### Problem Statement

Develop Expert System by creating knowledge base of facts and rules for specialized knowledge domain of your choice.

### Domain

Hospital Patient Diagnosis

### Description

This project implements a simple rule-based Expert System using Prolog. The system accepts three symptoms from the user and applies predefined rules to identify a possible condition.

### Conditions

- Fever
- Cold
- Flu
- Stomach Problem
- Sore Throat

### Technology Used

- Prolog
- SWI-Prolog

### How to Run

1. Open the program in SWI-Prolog.
2. Load `hospital_diagnosis.pl`.
3. Run the query:

start.

4. Enter three symptoms when asked.

### Sample Input

fever.
cough.
body_pain.

### Sample Output

Possible Condition: flu

Recommendation: Take rest and drink enough fluids.

### Result

The Expert System successfully matches the entered symptoms with predefined rules and displays the possible condition and recommendation.
